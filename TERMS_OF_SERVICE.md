## 1. Description of Service

ShittyTFTBot is a Discord bot designed for managing and interacting with players and data related to Teamfight Tactics (TFT). The Bot provides features including but not limited to:

- Looking up TFT player statistics and match history
- Retrieving ranked cutoff data from the Riot Games API
- Simulating TFT shop rolls
- Displaying augment, item, unit, and trait data
- Retrieving and displaying random channel messages for entertainment
- Submitting suggestions
- Moderation tools (anti-invite, message logging, spam catching, purge, timeout)
- Streamer-related content and community commands
